# Raccourcis clavier

Tous les raccourcis sont également consultables dans l'application via le menu **Aide > Raccourcis clavier**.



## Fichier

| Raccourci | Action |
|:---------:|--------|
| `Ctrl+N` | Nouveau projet (nouvelle fenêtre) |
| `Ctrl+O` | Ouvrir un projet `.pnlg` |
| `Ctrl+S` | Enregistrer le projet courant |
| `Ctrl+Shift+S` | Enregistrer sous… |

## Édition

| Raccourci | Action |
|:---------:|--------|
| `Ctrl+Z` | Annuler |
| `Ctrl+Y` | Rétablir |


## Imports

| Raccourci | Action |
|:---------:|--------|
| `Ctrl+I` | Importer un fichier BXF2 (Imos) |
| `Ctrl+Shift+I` | Importer un fichier CSV |

## Navigation

| Raccourci | Action |
|:---------:|--------|
| `Ctrl+1` | Onglet Pièces |
| `Ctrl+2` | Onglet Stock |
| `Ctrl+3` | Onglet Réglages |
| `Ctrl+4` | Onglet Résultats |

## Aide

| Raccourci | Action |
|:---------:|--------|
| `F1` | Ouvrir la documentation en ligne |

## Formulaires

Ces raccourcis fonctionnent dans tous les formulaires de Panelgator (ajout/édition de pièce, ajout de matériau, modale d'import…).

| Raccourci | Action |
|:---------:|--------|
| `Entrée` | Champ suivant (validation et passage au champ d'après) |
| `Ctrl+Entrée` | Soumettre le formulaire |
| `Échap` | Réinitialiser le formulaire ou fermer la modale |
| `Tab` | Champ suivant |
| `Shift+Tab` | Champ précédent |
| `+ − * /` | Opérations mathématiques dans les champs numériques (ex. `2800-2*19` donne 2762) |

## Sélecteur de chants

Quand le focus est sur le sélecteur de chants d'une pièce :

| Raccourci | Action |
|:---------:|--------|
| `Espace` | Activer/désactiver tous les chants |
| `↑` | Activer/désactiver le chant haut |
| `↓` | Activer/désactiver le chant bas |
| `←` | Activer/désactiver le chant gauche |
| `→` | Activer/désactiver le chant droit |

## Visualisation des résultats

Quand l'aperçu d'un panneau est affiché dans l'onglet Résultats :

| Raccourci | Action |
|:---------:|--------|
| `Ctrl+Molette` | Zoom centré sur le curseur |
| Double-clic | Réinitialiser le zoom |
| Glissé souris | Déplacer la vue |

## Touche Échap (contextuelle)

`Échap` a un comportement contextuel :

- Dans un formulaire : réinitialise les champs
- Dans une modale : ferme la modale
- Dans la liste de pièces avec sélection active : annule la sélection
- Sinon : aucun effet
